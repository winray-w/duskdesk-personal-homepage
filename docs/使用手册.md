# DuskDesk 个人主页模板使用手册

[返回中文 README](../README.md) · [English README](../README.en.md)

## 1. 从哪里开始

把整个模板文件夹保存到自己的电脑，用 VS Code 打开文件夹，然后双击 `index.html` 查看页面。Windows 的 `start-preview.cmd` 同样会直接打开网页，不会启动服务器。

一般情况下，只需修改 `site.config.js` 并替换头像。该文件以普通脚本加载，因此直接打开本地 HTML 也能工作。保存后刷新网页；弹窗已经打开时，刷新后重新打开。

模板中的 `Your Name`、示例项目与通用头像是占位内容，GitHub 和邮箱默认留空。

## 2. 修改个人信息

打开 `site.config.js`，保留 `window.SITE_CONFIG = { ... };` 结构，只修改需要的值。

| 字段 | 用途 | 填写提示 |
| --- | --- | --- |
| `name` | 顶栏、首页问候、名片、关于我及窗口底栏 | 建议使用简短昵称；窗口底栏自动同步 |
| `pageTitle` | 浏览器标签页标题 | 与姓名一起修改；设为空字符串时自动生成 |
| `description` | 页面简介元数据 | 简短介绍自己和网站 |
| `desktopLabel` | 顶栏姓名右侧文字 | 默认“的灵感桌面” |
| `avatar` | 首页及关于我的头像 | 如 `assets/avatar.jpg` |
| `avatarAlt` | 头像替代文字 | 如“我的个人头像” |
| `tagline` | 名片与关于我中的座右铭 | 建议短句 |
| `introNote` | 首页标题上方文案 | 建议一行内的短句 |
| `welcome` | 首页问候下方文案 | 建议一句话 |
| `status`、`greeting` | 名片下方两段文字 | 建议保持简短 |
| `footerNote` | 页面左下角文字 | 如“持续创造中” |
| `about.motto` | 关于我中的中文寄语 | 一句话即可 |
| `about.bio` | 关于我中的个人简介 | 兴趣、学习方向、经历等 |
| `projectsIntro` | 项目合集开头说明 | 简述你的作品方向 |
| `projects` | 项目列表 | 参见第 4 节 |
| `contact.intro` | 联系窗口介绍 | 一句话即可 |
| `contact.github` | GitHub 主页完整网址 | 留空则隐藏此项 |
| `contact.email` | 公开联系邮箱 | 留空则隐藏此项 |
| `contact.note` | 联系窗口底部文字 | 自由修改 |

部分页面装饰文案保留在 `index.html`，例如海报大标题 `Bring ideas to life`、底部的 `Make something you love.` 和“造物匣”栏目名称。修改 `tagline` 不会改变海报大标题：它由多个单词与字母组成拼贴排版，若要改动，请搜索 `<h1` 并同时调整其 `aria-label` 与外层 `section` 的 `aria-label`，再检查手机布局。

### 配置写法

```js
name: '你的昵称',
pageTitle: '你的昵称 — 我的作品空间',
avatar: 'assets/avatar.jpg',
about: {
  motto: '保持好奇，持续创造。',
  bio: '你好！我喜欢编程、摄影和记录日常。这里分享我的作品与学习过程。',
},
```

这段代码用于替换原配置中的对应字段，不要在同一对象中重复添加同名字段。每项之间保留逗号，文字保留引号。文字中包含英文单引号时，可以改用双引号：`name: "I'm a maker"`。配置是 JavaScript 对象，支持注释和末尾逗号。

所有简介和项目描述都按纯文本显示。不要在配置里填写 `<br>` 或其他 HTML 标签；它们会原样显示。

## 3. 替换头像与网站图标

1. 将自己的 JPG、PNG、WebP 或 SVG 图片放入 `assets/`，推荐使用正方形头像，例如 512 × 512。
2. 设置 `avatar: 'assets/你的文件名.jpg'`，并修改 `avatarAlt`。使用网页相对路径及正斜杠，不要填写电脑上的 `D:\...` 路径。
3. 头像会同步显示在首页名片和关于我窗口。图片加载失败时回退到模板头像。
4. 如需更换浏览器标签图标，替换 `assets/favicon.svg`。使用 PNG 时，同时修改 `index.html` 中的图标 `href` 和 `type="image/png"`。

默认头像是模板内的通用 SVG 图形；替换头像后，如果仍需加载失败回退，请保留 `assets/avatar.svg`。

## 4. 修改、增加与删除项目

`projects` 是一个数组，每个 `{ ... }` 对应一张项目卡片及一个详情窗口。无需修改窗口编号或 `app.js`。

每个项目支持以下字段：

| 字段 | 显示位置 |
| --- | --- |
| `name` | 卡片标题、窗口标题、项目详情标题 |
| `summary` | 卡片简介与详情摘要 |
| `caption` | 项目展示区的短文字或路径装饰 |
| `tag` | 详情右侧分类标签 |
| `description` | 项目完整介绍 |
| `highlights` | 亮点列表，每项包含 `title` 和 `text` |
| `url` | 详情中的“查看项目”按钮；留空隐藏 |

例如，将整个 `projects: [...]` 替换为：

```js
projects: [
  {
    name: '我的第一个作品',
    summary: '一个记录日常灵感的小工具',
    caption: '~/projects/idea-notes',
    tag: 'Web 工具',
    description: '在这里介绍作品的用途、实现方式与完成成果。',
    highlights: [
      { title: '功能', text: '记录、整理与查找自己的灵感。' },
      { title: '实现', text: '介绍自己实际使用的技术。' },
    ],
    url: 'https://example.com', // 替换为自己的真实网址
  },
  {
    name: '摄影集',
    summary: '收藏生活中的光影',
    caption: 'A collection of moments',
    tag: '摄影',
    description: '这里展示我的摄影作品与拍摄故事。',
    highlights: [],
    url: '',
  },
],
```

添加项目：复制一个完整项目对象，放到数组中，用逗号与前一项分隔。删除项目：删除对应对象。调整顺序：移动对象的位置。暂不展示任何项目：使用 `projects: []`，合集会显示“新的作品正在酝酿中”。项目较多时在窗口内滚动。

`url` 和 GitHub 网址须为完整 `https://` 或 `http://` 地址。空值、缺少协议或其他协议不会生成外部链接。

## 5. 填写联系方式

```js
contact: {
  intro: '欢迎交流作品和想法。',
  github: 'https://github.com/your-username',
  email: 'hello@example.com',
  note: '期待收到你的消息。',
},
```

替换示例中的账户和邮箱。GitHub 链接在新标签页打开；邮箱通过 `mailto:` 请求打开访客设备的邮件客户端，不会由网站直接发送邮件。

不想公开某项时填 `''`。两项都留空时显示“联系方式待填写”。配置中的信息会公开，请仅填写计划展示给访客的内容。

## 6. 调整主题与动画

`style.css` 开头的 `:root` 包含主题颜色：

| 变量 | 默认色 | 用途 |
| --- | --- | --- |
| `--ink` | `#352a49` | 深色文字 |
| `--cream` | `#fff0d5` | 奶油色文字 |
| `--peach` | `#f9ba91` | 落日橙点缀 |
| `--pink` | `#e5a2b7` | 粉色点缀 |
| `--plum` | `#524264` | 紫色辅助 |
| `--paper` | `#faf1e3` | 纸感窗口背景 |

背景渐变在 `.wallpaper`，城市与小猫颜色在 `index.html` 的 SVG 中。它们包含独立颜色值，修改主题变量不会自动改变所有背景颜色。布局和动画主要在 `layout.css`。

访客可点击底部的动态按钮，统一暂停或开启动画。系统开启“减少动态”时，页面默认暂停。页面显示的是访客设备的本地时间；“落日放映中”是装饰文字，没有接入实时天气服务。

## 7. 本地预览与检查

直接双击 `index.html` 即可运行；需要 HTTP 地址时，在安装了 Node.js 的电脑上打开本目录终端：

```sh
node server.cjs
```

打开 `http://127.0.0.1:4173`；按 Ctrl+C 停止。端口被占用时，Windows CMD 可以运行：

```bat
set PORT=4174
node server.cjs
```

PowerShell 可以运行：

```powershell
$env:PORT = '4174'
node server.cjs
```

然后访问终端打印的地址。预览服务只监听本机。

修改后建议检查：

- 标签页标题、顶栏昵称、头像、个人介绍是否正确。
- 每张项目卡片能否打开对应详情，返回按钮是否回到合集。
- GitHub 与项目链接是否指向自己，邮箱是否正确。
- Esc、关闭按钮、窗口外部点击及动态开关是否正常。
- 缩窄浏览器到手机尺寸后，文案是否过长、弹窗是否可滚动。

名字和首页短文案建议保持简洁；大量介绍放在关于我或项目详情窗口中。

## 8. 部署网站

模板是纯静态站点，无需运行构建命令，也不需要后端。将下列文件与目录作为同一个网站根目录上传到静态托管服务：

```text
index.html
site.config.js
personalize.js
app.js
style.css
layout.css
assets/
```

保证 `index.html` 位于上传根目录，文件名大小写一致。不要遗漏新增的两个脚本：`site.config.js` 和 `personalize.js`。它们与 `app.js` 的加载顺序已经在 HTML 中配置好。

部署运行文件时，不需要上传 `server.cjs`、`start-preview.cmd`、`.git/`、截图或压缩包。GitHub 上保存源码时可以保留预览工具、README 和使用手册，方便别人下载使用。

后续更新：修改本地配置或图片，预览检查，然后重新上传对应文件。使用 Git 自动部署时，在自己的仓库中提交更新，由已配置的托管流程发布。本模板没有预设任何账号、域名、访问令牌或自动部署流程。

## 9. 常见问题

**保存后页面没变化。** 确认打开的是正在编辑的模板目录，然后刷新页面；必要时使用 Ctrl+F5。弹窗内容在脚本初始化时生成，修改后需要刷新。

**姓名改了，但浏览器标题还是原来的文字。** `pageTitle` 是独立字段，也需要修改；留空可按姓名自动生成。

**头像不显示。** 检查路径、大小写、扩展名，确认图片已经放入 `assets/` 并随网页上传。

**弹窗打不开，时钟停在 `--:--`。** 检查配置的逗号、引号、大括号和数组方括号是否完整，确认三个 JS 文件均能加载且顺序保持为配置、内容填充、交互。按 F12 查看控制台错误位置。

**项目没有“查看项目”按钮。** `url` 为空或不是完整 HTTP(S) 地址时会隐藏按钮。

**点击邮箱没有反应。** 设备需要配置邮件客户端，也可以从页面复制邮箱地址自行发信。

**部分字体和截图不同。** `style.css` 使用 Google Fonts 加载增强字体，网络不可用时使用系统回退字体。字体服务的可用性和不同设备的系统字体可能影响显示效果；无需额外安装字体即可使用。

**希望正式开源。** 维护者可在发布前添加自己选定的 `LICENSE`，完善仓库说明，并确认示例内容已经替换或明确保留为模板占位。此目录尚未指定许可证。
